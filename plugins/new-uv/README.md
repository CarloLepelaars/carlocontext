# new-uv

Scaffold a ready Python repo from [CarloLepelaars/uv_template](https://github.com/CarloLepelaars/uv_template). Clones the template, renames the package, replaces every template name, then runs `uv sync` and ruff + pytest.

Install from the [marketplace README](../../README.md). Invoke with `/new-uv my-lib`.
