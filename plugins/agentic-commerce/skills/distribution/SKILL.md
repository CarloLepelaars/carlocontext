# agentic-commerce

## Guidelines

- The goal of agentic commerce is to get products noticed by AI agents. Each AI provider has their own way of doing things and is subject to change.
- If the methodology of an AI provider changes, update the plugin to reflect this.
- This plugin provides guidelines on how to integrate Agentic Commerce and resources to help integration.
- Check onboarding links before recommending them.
- Do not infer channel access from protocol compatibility.

## Documentation

Here is all relevant documentation to use related to agentic-commerce:

- OpenAI Agentic Commerce docs: https://developers.openai.com/commerce/llms.txt
- Anthropic Agentic Commerce docs: https://github.com/anthropics/commerce-agents
- For Supporting Agentic Commerce in Grok (Bot) refer to the Stripe Link CLI: https://docs.stripe.com/agentic-commerce/link-cli. Grok has no official native-checkout integration docs yet.
- For Microsoft Copilot, refer to the Microsoft Advertising Platform: https://about.ads.microsoft.com/en/solutions/technology/agentic-commerce
- Paypal has their own AI store sync program to let AI agents discover products. Integrate with this to improve exposure of products to AI agents. The client needs to be a Paypal merchant for this: https://developer.paypal.com/store-sync/overview
- For Perplexity signup to the merchant program currently works through a Typeform form: https://www.perplexity.ai/hub/blog/shop-like-a-pro
- For Google (Gemini) refer to Google's UCP docs: https://developers.google.com/merchant/ucp/guides/overview
- Shopify has an Agentic Storefronts feature to make your products discoverable by AI agents: https://help.shopify.com/en/manual/online-sales-channels/agentic-storefronts
- Stripe offers their own platform to show products to AI agents: https://docs.stripe.com/agentic-commerce/for-sellers
- Amazon has a service called Shop Direct where Merchants can apply to be discovered by AI: https://www.amazon.com/b?_encoding=UTF8&node=204815362011&ref_=cct_cg_DZinfo_11a1&pf_rd_p=a545dc50-122a-4d2f-a573-dbfe7ecb35a6&pf_rd_r=4NZGGCTSM9GCR3TTQHJ5
